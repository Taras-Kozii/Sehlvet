Sehlvet is a modern responsive landing page created for a brand in the outdoor design, terrace solutions, or premium exterior products industry. The landing page is designed in a modern minimalist/premium style with an emphasis on large visual blocks and structured content presentation. The interface is built to highlight product quality, improve information perception, and provide an intuitive navigation experience across all device types.

## 🔗 Live Demo

[Sehlvet](https://taras-kozii.github.io/Sehlvet/)

## 🚀 Core Technologies

- HTML5 — semantic page structure
- CSS3 — styling, responsive layout, and UI animations
- JavaScript (Vanilla JS) — interactivity and interface behavior
- Responsive Web Design (RWD) — adaptation for mobile/tablet/desktop
- Flexbox & CSS Grid — building a modern layout system
- CSS Transitions & Animations — smooth hover effects and transitions
- Git & GitHub Pages — version control and project deployment
